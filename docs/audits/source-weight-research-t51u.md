## The two integrative sources

The Token recommendation rule (PR #994, merge `e2095cfa`, `docs/PROJECT_NOTES.md` line 2203) says: “When sources disagree on a token, the two integrative medicine sources hold more weight than a simple majority. FDA, CIR, and FEMA are supporting sources. They do not override the integrative sources when those two agree.”

That sentence does not name the two sources. The PR #994 body does not name them either. Methodology §4a Tier 2/3 and `docs/SOURCES.md` list a group (Natural Medicines Database, NIH NCCIH, MSK About Herbs, Examine.com, ConsumerLab/NSF/USP, EMA herbal monographs, German Commission E, ESCOP, American College of Lifestyle Medicine, and others). That is a list, not a designated pair. No pair was chosen for this pass, and no source position was invented.

Because the pair is not named, every string below is **not covered** by source A and **not covered** by source B. There is no would-change token. FDA, CIR, and FEMA were not used as a substitute.
