# Know Your Remedy — Sources

Working bibliography for founder-call packets and ingredient taps.
**Methodology §4a owns the hierarchy and the grade.** This file lists where we look.
FDA / GRAS / IID = inventory and label context. Never “it’s legal so it’s Clean.”
Majority of independent sources wins when agencies split. 1 scare paper ≠ Avoid. 1 “fine” paper ≠ Clean.

Label truth (not a grade source)
- DailyMed / FDA SPL — Drug Facts, Other Ingredients, NDC/set-id
- NIH Dietary Supplement Label Database (DSLD)
- Brand site Other Ingredients / Supplement Facts
- Store PDP gallery photos of the carton (store HTML is not OI)
- Carton in hand / founder photo

- EMA excipient labeling
- Health Canada / NNHPD
- UK FSA
- FSANZ
- Japan MHLW
- WHO / JECFA
- IARC Monographs
- US NTP / Report on Carcinogens
- NIEHS
- EPA IRIS
- ATSDR

- PubMed / PMC primary studies
- Cochrane
- National Academies
- UCSF / FDA CERSI Excipients Browser
- Handbook of Pharmaceutical Excipients

- Map names via CAS / UNII / E-number / FD&C

Tier 2/3 — integrative / natural-medicine (required on packets, not optional)

Citation-only, never treat as the study: Institute for Functional Medicine, AANP positions, functional-medicine authors, brand/wellness blogs

Oils — INFO ONLY, never a Search Clean/Caution/Avoid
- Valerie Ann Worwood, The Complete Book of Essential Oils and Aromatherapy (and later Worwood safety texts)
  Attribute Worwood. Write original copy. Never paste her charts, recipes, or long excerpts.
- Tisserand & Young, Essential Oil Safety (when a safety conflict needs a second technical text)
- NCCIH herb/oil pages when they exist
- Bottle oils on a brand sweep = name + URL hunt list only

How a packet uses this file
- Methodology §4a 7-step is the official workflow: (1) EFSA/EU (2) FDA/IID/GRAS context only (3) IARC + NTP + Prop 65 (4) Health Canada or EMA if relevant (5) one or two key primary papers (6) EWG/CSPI if they flag it — advocacy, not the vote (7) founder call.
- Also: label first (DailyMed / DSLD / brand OI / carton). Store HTML is not Other Ingredients.
- Also: when the question is harm-in-this-form, include at least one Tier 2/3 integrative source (Natural Medicines, NCCIH, MSK About Herbs, Examine, Commission E, etc.).
- Majority of independent sources wins. Split → Brandon. Do not invent a live grade.
- After a lock, add the citation to this file if it is new.

Do not turn this into a 400-row dump of every PubMed URL on day one. Add as we cite.
